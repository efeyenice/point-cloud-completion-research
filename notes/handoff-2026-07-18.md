## 1. The four lessons (memorize these, they are the project's debugging history)

| run | color result | root cause | fix |
|---|---|---|---|
| 1 (07-12) | froze at init (0.103) | full-run LR schedule decays per *epoch* = per step at batch 1 → LR collapsed ×0.06 mid-gate | gates use constant LR 5e-4 (`lr`/`lr_step` overrides in `run_training`) |
| 2 (07-13) | crawled 0.166→0.031, plateaued | sigmoid+MSE logit gradient carries σ′ → vanishes at extreme targets (white/navy = ShapeNet's palette) | color TRAINS with soft-target BCE (grad = σ−t); MSE stays the metric |
| 3 (07-13) | flat ~0.14, and geometry destabilized (cd 2.3× A's, oscillating) | BCE's strong gradients through the SHARED decoder perturbed geometry → churned NN correspondences → color targets flipped → closed interference loop | **decoupled color heads** on detached features; arm B geometry ≡ arm C by construction (unit-tested: geometry grads bitwise-identical with color on/off) |
| 4 (07-18) | bulk instant (0.036 @ step 249), edges crawled, stuck 0.0174; geometry now ≡ A (0.0152 vs 0.0151) | **spectral bias**: for one memorized sample the color head is a raw-xyz coordinate MLP; sharp texture edges fit exponentially slowly (NeRF lesson) | **Fourier positional encoding** (8 bands) on the color head's position input |

Run 4's probe also produced a metric insight: the color MSE bottoms out at the **oracle NN-painter
floor** (repaint each predicted point with its nearest-GT color; the residual is correspondence
ambiguity at color edges and varies per texture). Fixed-constant gate bars were guesses, twice
wrong. The gate is now **oracle-calibrated**: pass = within 2× of the measured floor or < 5e-3
absolute; the floor is printed with every eval (`val_color_oracle`). CPU stripe regression: PE
model 0.035 ≈ floor 0.042; raw model 0.104 ≫ floor; frozen color ~0.10+ fails everywhere.

## 2. Scientific-integrity ledger (what changed about the EXPERIMENT, not just code)

- **Arm B is now *decoupled* joint prediction** (color paints, never steers). Geometry story = A vs
  C; B vs C geometry = consistency check; coupled-λ training = banked ablation. (ADR-0006 am. 4.)
- **Run-3's interference is a reportable negative finding**: naive fully-coupled xyzrgb training
  destabilized both modalities — same shape as the field's "naive fusion hurts" lesson (ViPC).
- **Color quality is always reported relative to the oracle floor** — a defensible metric practice
  for the advisor/paper. (ADR-0006 am. 5.)

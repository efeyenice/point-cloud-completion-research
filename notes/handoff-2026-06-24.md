## 2. The decisions, in one place (the "why")

- **Naive-first (ADR-0001).** Sample directly with CloudCompare, NO ambient-occlusion dedup.
  Output WILL show salt-and-pepper color speckle from ShapeNet's duplicate faces — that is
  EXPECTED and is the teaching artifact. The fix (EPFL AO + duplicate-face removal, vendored at
  `tools/mesh-sampling/mesh_sampling_geo_color_shapenet.py`) is iteration 2.
- **Scope boundary (ADR-0002).** We output raw colored PLYs (native coords, 100k pts) + manifest.
  Teammate **Pelin** owns normalization / FPS / partial–complete pairs downstream.
- **Shared Drive (ADR-0003/0004).** Project Drive = "Point Cloud Completion/" (under *Shared with
  me*) → `Efe/`, `Ortak/`, `Pelin/`. Each teammate adds a one-time *Add shortcut to Drive* so paths
  resolve identically. ShapeNet zips live in `Ortak/data/shapenetcore/`; outputs go to
  `Ortak/colored_pc/`. Reading the shared zips means **Pelin needs NO HuggingFace access** (the
  decisive reason for caching data in the shared Drive).

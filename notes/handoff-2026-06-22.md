## 1. Current direction (what we're building)

Per-point **colored completion (XYZRGB)** — W3 deck by teammate **Pelin**. Two variants:
`XYZRGB→XYZ` (color in, geometry out) and `XYZRGB→XYZRGB` (joint geometry+texture, the novel one).
**North star: avoid 2D guidance images** (deliberate divergence from the ViPC/EGIInet image-guided line).

## 2. What this session did (reading + data tooling)

Guided deep-reads (researcher reads alongside; lens = problem→method→math→key table→limits→RGB lens).
Full teardowns are in the chat transcript + memory; **do not re-teach** — just the deltas:

- **ShapeNet (2015, arXiv:1512.03012)** — `papers/ShapeNet.pdf`. Dataset/infra report. For us: ShapeNetCore
  (55 cats) is the base; **color/texture is NOT a curated annotation** (it lives in source OBJ+MTL+textures);
  WordNet synset IDs = on-disk folder names; alignment is delivered & useful.
- **PointDreamer (2024, arXiv:2406.15811)** — `papers/PointDreamer.pdf`. Colored-PC→textured-mesh (NOT
  completion). For us: (a) copy its data recipe = sample xyz+rgb from textured meshes; **chair/car/motorbike =
  the texture-rich ShapeNet cats**; (b) its method (project→2D-diffusion→unproject) is the image route we
  AVOID; (c) it sits *downstream* of completion. Lesson: predicting color in 3D tends to be **blurry**.
- **EPFL color-sampling (2022, arXiv:2201.06935)** — the data-gen tool. **Vendored + committed** to
  `tools/mesh-sampling/` (commit `ce44f70`). Fixes ShapeNet **dual-face color corruption** via ambient-occlusion
  internal-face removal. Built for *compression* (outputs a voxelized 1024³ grid), so we use its front half and
  replace its back half. Full teardown in chat; key facts in memory `w3-colored-completion-direction.md`.

## 3. NEXT STEPS — the actual work queue

**Adapt the EPFL script** `tools/mesh-sampling/mesh_sampling_geo_color_shapenet.py` into a completion-data generator:

1. **Modernize / make it run.**
   - Verify/fix the pymeshlab AO call at **line 138** (`ms.ambient_occlusion(occmode=1)` was likely renamed in
     newer pymeshlab — check `pymeshlab.MeshSet().print_filter_list()`; either pin `pymeshlab==2021.10` or update the call).
   - Fix `python`→`python3` in the subprocess at **line 159**; ensure the module is importable from cwd.
   - Install **CloudCompare** binary (the script shells out to it at line 236); use `xvfb-run` if headless.
2. **Replace the voxelization back half (lines 243–256)** with completion normalization:
   FPS → fixed N (e.g. 2048 partial / 8192–16384 complete) · center + scale to **unit sphere** (float coords) ·
   optional **RGB→L\*a\*b\*** (better for a color-difference loss; see "Head Completion" note in W3).
3. **Add a partial-view generator:** from each complete colored cloud, Open3D **hidden-point-removal** from K
   viewpoints → `(partial, complete)` XYZRGB pairs. (Data degradation, not method-level image guidance — consistent
   with the no-images rule.)
4. **Sanity-check** on ~5 chair/car/motorbike meshes (`--remove_intermediate_files False`; compare to mesh render;
   confirm **no salt-and-pepper color** = dual-face fix fired).

Knobs to remember: `--occlusion_threshold` (face-cull aggressiveness, default 0) · `--target_points` (default 10M,
lower for us). Full knob table + gotchas are in memory `w3-colored-completion-direction.md`.

**Parallel track (separate):** stand up the geometry-only PoinTr baseline (`CLAUDE.md §5`, yuxumin/PoinTr) to

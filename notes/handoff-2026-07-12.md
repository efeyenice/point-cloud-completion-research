## 2. The decisions, in one place (the grilling outcomes)

1. **"Baseline" disambiguated.** This week's baseline = **geometry-only PCN on our s4 data** (the
   *s5 baseline*). The published PoinTr ≈2.851 reproduction is a separate later milestone.
2. **Three arms, one config-driven model:** A `xyz→xyz`, B `xyzrgb→xyzrgb`, C `xyzrgb→xyz`.
   A→C = effect of color **input**; C→B = effect of jointly **predicting** color. A-vs-B alone
   would be confounded.
3. **PCN from scratch in PyTorch** (no CUDA extensions; pure-torch Chamfer). Structure
   cross-checked against qinglew/PCN-PyTorch but owned line-by-line.
4. **`meshray_nn` partials only** this week (ADR-0005's reference); tex/ptproj = banked ablation.
5. **Overfit ladder as hard gates** (1 pair → 10 pairs → full runs), split **by model** (16/4 per
   category) — never by pair (8 views of a model would leak).
6. **Full metrics set:** CD-L1 + CD-L2 (×10³, conventions written in the ADR/notebook), F-score@1%,
   color MSE/PSNR at xyz-NN correspondence (arm B), curves, fixed val panels, final A/B/C table.
7. **Sizing:** input 2048 → coarse 1024 → **2×4 folding grid → fine 8192 = GT size**.
8. **Compute: Colab Pro (T4/L4);** checkpoint/resume built in regardless (`RESUME=True` in T9).

Also: color-ok filtering (GT color std > 0.01, ~58/60 models) applies to **every** arm, so all arms
see identical data; rgb stays raw [0,1] (naive-first, no Lab); native `model_normalized` frame kept.

## 3. Validated vs needs-Colab

  - split determinism, no train/val model leakage, deterministic val subsampling.
